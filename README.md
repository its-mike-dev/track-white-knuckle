# SISYPHUS // 15

Custom Challenge Mode megacomplex map and gameplay mod for **White Knuckle** (built for BepInEx 5 + WKMapLoader 1.3.2).

- **Download & Install Guide (Windows / Linux / Steam Deck):** https://its-mike-dev.github.io/sisyphus-15/
- **Discord (WK // Maps & Mods):** https://discord.gg/Nqj8FjtP8c

## Quick install

1. Install **BepInEx 5 (x64)** and **WKMapLoader 1.3.2** in your `White Knuckle` folder.
2. Extract `downloads/SISYPHUS_15_v1.0.zip` into `White Knuckle/BepInEx/plugins/`.
3. On Linux / Steam Deck, set Steam Launch Options to `WINEDLLOVERRIDES="winhttp=n,b" %command%`.
4. Launch White Knuckle, open the **CUSTOM** tab, and pick **SISYPHUS // 15**.
